# ASIC-Implementation-of-Reversible-Compressor
🔐 RTL-to-GDSII implementation of a high-performance reversible 4:2 compressor with ancilla optimization using Verilog HDL and Cadence tools. Includes functional verification, ASIC synthesis, Physical Design, STA, and complete RTL-to-GDSII flow for low-power VLSI and quantum computing applications.
